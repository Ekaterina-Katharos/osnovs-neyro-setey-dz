# Часть 2. Подготовка данных и CLI-утилита

Реализована утилита для сканирования данных и проверки окружения.

## Команды:
- `python app/cli.py prepare --path <путь> --ext <расширения> --output <файл.npy>` — сканирует папку, нормализует данные и сохраняет в .npy.
- `python app/cli.py doctor` — проверяет версию Python, наличие библиотек и CUDA.

## Настройки
Пути по умолчанию берутся из файла `.env` (переменная `DATA_PATH`).
