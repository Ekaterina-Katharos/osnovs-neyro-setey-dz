# Практическое задание по дисциплине "Основы нейронных сетей"

Данный репозиторий содержит выполнение практического задания, состоящего из трех частей.

## Структура проекта:
*   `part1_mlp/` — Объектно-ориентированная реализация многослойного перцептрона.
*   `part2_prepare/` — CLI-утилита для подготовки и нормализации данных.
*   `part3_parallel/` — Многопоточная и многопроцессорная обработка данных (аугментация).
